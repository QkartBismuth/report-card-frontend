# Рапортичка — Android-приложение

Flutter-клиент учёта посещаемости для учебного заведения (колледжа). Работает в паре
с backend ([report-card-backend](https://github.com/QkartBismuth/report-card-backend)).
Система рассчитана на все группы колледжа: староста ведёт рапортички своей группы,
преподаватели подтверждают и выгружают, администратор управляет группами, преподавателями
и устройствами, а расписание пар загружается из АИС КТК и автоматически подкладывается под рапортичку.

## Возможности

- Авторизация с сохранением сессии; выбор темы оформления (светлая / тёмная / системная / OLED).
- Роли:
  - **Староста** — создаёт сессии на текущий день, выбирая предмет из общего каталога; отмечает посещаемость; загружает `.docx` со списком группы; ведёт расписание группы.
  - **Преподаватель-куратор** — видит группу целиком; подтверждает/снимает подтверждение сессий; выгружает.
  - **Преподаватель-предметник** — видит только пары своих предметов; смотрит расписание группы (только чтение).
  - **Администратор** — раздел «Администрирование»: студенты любых групп, преподаватели, группы и кураторы, подключённые устройства, ошибки, подключение (адрес сервера, Wi-Fi, туннель, рассылка нового адреса всем устройствам).
- **Расписание КТК**:
  - Экран «Расписание»: мастер выбора отделения → курса → группы (с поиском по номеру, например «БД.09.23.1»).
  - Загрузка недельного шаблона с сервера.
  - Правка шаблона: изменить/добавить/удалить пару, исправить номер пары, кабинет, преподавателя, пометить «отменена».
  - **«Создать на сегодня»** — сессии на все пары дня по расписанию: режим «дописать недостающие» или «синхронизировать» (удалить лишние неподтверждённые).
- **Авто-настройка**: сервер опрашивается каждые ~10 секунд; по push-конфигу меняется адрес сервера и подключается заданный Wi-Fi автоматически.
- **Телеметрия**: регистрация устройства, отправка ошибок на сервер (видны администратору).
- Для преподавателя сессии группируются **по дням**: одна запись на день → подтверждение и выгрузка всего дня одной кнопкой.
- Каталог предметов загружается автоматически (у преподавателя — «Мои предметы»).
- Выгрузка рапортички в PDF / DOCX / XLSX (одна сессия, один день, период).

## Стек

- Flutter 3.x · Dart SDK `^3.13.2`
- `provider` (состояние), `http` (API), `shared_preferences` (сессия, настройки, тема)
- `intl` (даты), `file_picker`, `open_filex`, `path_provider` (загрузка/открытие файлов)
- `device_info_plus` (телеметрия), `wifi_iot` + `permission_handler` (авто-Wi-Fi)

## Требования

- Flutter SDK 3.27+ (stable)
- Android SDK (для сборки под Android)
- Работающий backend (см. `report-card-backend`); для расписания — доступ к `http://mob.kansk-tc.ru/ktc-api` на сервере

## Запуск

```bash
flutter pub get

# адрес backend указывается при запуске/сборке:
flutter run --dart-define=API_URL=<адрес_сервера>
```

Без `--dart-define` используется значение по умолчанию из `lib/config.dart`.

## Сборка APK

```bash
flutter build apk --release --dart-define=API_URL=<адрес_сервера>
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`. Иконка приложения — адаптивная (Android 8+) на основе `ico.svg`.
